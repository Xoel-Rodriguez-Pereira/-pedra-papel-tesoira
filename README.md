# -pedra-papel-tesoira
Piedra, Papel, Tijera, Lagarto, Spock es una variante del clásico juego, popularizada por The Big Bang Theory y creada por Sam Kass en 1998 para reducir los empates. Añade dos elementos a los tres originales, creando 10 combinaciones posibles donde cada uno gana a dos y pierde contra otros dos.
